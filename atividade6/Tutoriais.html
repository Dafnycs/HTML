Tutoriais de tecnologia

1 Como instalar o Visual Studio Code

Objetivo

Aprender a instalar e configurar o Visual Studio Code (VS Code), um dos editores de código mais utilizados no mundo.

  • Baixar o instalador no site oficial.
  • Instalar o programa no windows.
  • Escolher extensões úteis, como Python.
  • Criar e salvar o primeiro arquivo de código

    • Por que esse tutorial é importante

    O VS Code é uma ferramenta essencial para programadores. Com ele é possível escrever códigos em diversas linguagens, organizar projetos, executar programas e integrar o trabalho com o GitHub. Saber instalar e configurar o editor é um dos primeiros passos para começar a programar.

2 Como criar uma conta no GitHub

Objetivo

Criar uma conta no GitHub para armazenar projetos e códigos na internet.

  • Fazer o cadastro com e-mail e senha.
  • Confirmar a conta.
  • Configurar foto, nome e descrição do perfil.
  • Criar um repositório.
  • Enviar arquivos para o repositório.
